# L2 金样 — ooda 家族（循环过程产物）

> ooda 家族的产出是「过程 + 状态 + 总结」，不是单份报告。金样展示最小可回看的闭环组织。

## 元信息
- project: 通用输出模板构建
- skill_family: ooda
- 结构: work_ooda/{时间戳}-{任务名}/ 下

## 目录金样
```
work_ooda/20260826-000000-统一输出模板/
├── 00-目的.md        # 目的/成功标准/约束/理解回执/5W1H/U&Q
├── state.md          # 跨轮唯一真相源（本轮覆写）
├── 01-第一轮.md       # 本轮 Observe/Orient/Decide/Act/Verify
├── summary.md        # 总轮次 + 每轮摘要 + 成功标准验收
```

## 每轮问题分级（cspm 风格四档）
| 级别 | 含义 | 动作 |
|------|------|------|
| critical | 阻碍目标 | 本轮必须修 |
| major | 影响质量不阻塞 | 本轮优先修 |
| minor | 小瑕疵 | 成本低就修，否则下轮 |
| cosmetic | 格式命名 | 延后或跳过 |

## Observe 证据要求
- 每条发现标 [直接观察]/[AI推断]/[AI结论]
- 直接观察：纯感官事实，禁止规范性词汇
- 第2轮起追加 Delta（修复项/未动/新引入）

## 落盘
- 交付物写项目约定位置，禁止入 work_ooda/
- summary.md 关闭前写，逐条对照目的文件成功标准
